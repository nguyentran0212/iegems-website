# IEM Review Outline (post-2024 convention)

The canonical section structure for IEM reviews. The agent walks these in order. Skip only what the assessment genuinely has nothing to say about (rare).

## 1. Forewords

Static template. Use the canonical wording from the skill instructions. Variable fields: sample source, retail price, unaffiliated link.

## 2. In the Box

One or two paragraphs covering packaging and accessories. Mention everything the assessment file flagged as explicit, plus any obvious-to-assume items (case, cable, documentation) as `[VERIFY]` if not stated. End with a quick observation on the package presentation (compact, sturdy, basic, etc.). 100-150 words.

## 3. General Information

Paragraph form covering the unit itself. Two paragraphs typically:
- Paragraph A: Driver configuration, technology, what the IEM is, what the manufacturer's marketing claims are (with quick translation if the wording is jargon-heavy).
- Paragraph B: Build quality, materials, dimensions, weight, cable specs, connector type.

Add an FR graph if `assets/images/<Folder>/<name>_Graph_Harman.png` exists. Reference frequency response observations against the assessment file's section on tonality.

250-400 words total.

## 4. Experience

### 4.1 Physical Handling

Comfort during extended listening, fit and seal characteristics, cable quality, portability aspects. Discuss anything that physically interfered with enjoyment (cable tangles, fit issues, weight, nozzle comfort, included tips, or lack thereof).

Directly mines the session file's Non-sound aspects answers. Reference Gen's daily-driving notes ("for the better part of two weeks").

250 words.

### 4.2 Sound Signature & Tonal Balance

The longest section in most reviews. Setup:
- One paragraph on overall signature (V-shape, neutral, warm-neutral, U-shape, etc.), with the frequency-response observation tying it to measurement if available.
- One paragraph per the four tonal regions: bass, midrange, treble, sibilance handling. Pull from assessment track by track where specific cues were tested.
- One paragraph on tuning options (if the IEM has switches or nozzles), or the lack thereof.

Reference track callouts heavily. The agent should name at least one track from each dimension. Across the review, all dimensions (`/test-tracks`) should be touched at least once.

400-500 words.

## 5. Technical Performance

### 5.1 Resolution

Macro- and micro-resolution. Does the IEM survive complex mixes? How are decay tails, breath, micro-detail? Reference Ciaccona (Kavakos) and ABC feat. Sophia Black (Polyphia) as the canonical cues. Compare against the gate scale (Aria to Cantor) on the scale question if applicable.

200 words.

### 5.2 Soundstage & Imaging

Width, height, depth. Holographic impression. Imaging precision. Reference Gundam Seed Destiny OST "Memory" and Shadow of Baar Dau as the canonical cues. Comment on FPS-gaming if Gen plays; mark "not tested, does not game" if applicable.

150 words.

### 5.3 Bass Performance

Quantity vs quality. Texture and grip. Toe-tapping factor. Reference A Reckoning in Blood and Strength of a Thousand Men as the canonical cues. Cross-reference to physical-handling notes if the IEM is hard to drive.

200 words.

## 6. (Selected) Comparisons

Optional. Used by Gen when the assessment has direct A/B comparison notes. One to three IEMs per review. Each comparison: ~150-200 words framing the IEM against a comparator, on axes that differ between them.

Do not include this section if the assessment has no comparison data. Always include if the session file has a gate-comparison section.

## 7. Conclusions

The fixed Conclusions block. Two paragraphs of overall take in Gen's voice, then the bullet lists, then the rating block. See the skill instructions for the exact structure.

Reference the closing-take sentences from the session file. If the session file does not have them, ask Gen.

300-400 words total.
