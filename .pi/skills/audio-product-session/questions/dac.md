# DAC Assessment Questions

This document contains questions that I use to structure the experience I capture from listening to an DAC for the purpose of review.

The questions are organised into groups, reflecting different aspects of the DAC I review

## Non-sound aspects

*What do you think about the construction and design of this DAC? (Hardware design, size, weight, connection ports)*

*How is the latency of this DAC on wired and wireless connection?*

*What do you think about the software experience in general? (Fast? Slow? Buggy?)*

*Is there any particular software feature you want to mention in detail? (e.g., built-in DSP utilities, EQ)*

## Timbre and Tonality

*How do you describe the overall sound signature of this DAC?*

*How does this DAC balance different voices and instruments in a band?*

*How does this DAC balance different parts of a piano?*

*How does the midrange of this DAC handle vocals?*

*How does this DAC handle sibilant recordings?*

*How does this DAC reproduce strings and orchestra?*

## Bass and Dynamic

*How does this DAC convey "epic" bass lines?*

*How does this DAC handle a drum kit and bass guitar?*

*In conclusion, is this DAC ... toe-tapping?*

## Resolution

*Can this DAC handle complex, overlapping recordings?*

*Can this DAC handle recordings with congested lower frequencies?*

*How does this DAC convey micro details?*

## Spatial

*How does this DAC position instruments in a complex, 3D-sounding recording?*

*How does this DAC convey a sense of space in spacious recordings?*

*How does this DAC handles sound positioning in FPS games?*

## Pairing / Compatibility

*How does this DAC work with highly sensitive IEMs? (Any hiss or noise? Is there enough volume adjustment range?)*

*How does this DAC work with difficult-to-drive IEMs? (Any audible improvement compared to a weaker source? Does it lose any dynamic or impact compared to a reference desktop chain?)*

## Selected Comparisons

*Is there any other DAC, DAP, or source you would like to compare this device against? (Capture the comparison on any axes that are relevant.)*
